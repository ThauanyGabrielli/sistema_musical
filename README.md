

Um sistema web simples e intuitivo para gerenciamento de catálogo musical, permitindo o cadastro de artistas, registro de músicas, autenticação de usuários e visualização de repertório.

---

## 📁 Estrutura do Projeto

A organização de arquivos e diretórios do projeto segue a estrutura abaixo:

```text
sistema-musical/
├── .vscode/
│   └── settings.json         # Configurações do ambiente de desenvolvimento (VS Code)
├── index.html                # Página inicial / Dashboard principal do sistema
├── login.html                # Tela de autenticação e acesso de usuários
├── cadastro_artista.html     # Formulário para registro de novos artistas/bandas
├── cadastro_musica.html      # Formulário para cadastro de novas faixas musicais
├── listagem_musicas.html     # Tabela/Lista de visualização das músicas cadastradas
└── styles.css                # Folha de estilos global da aplicação
```

---

## 🚀 Funcionalidades

* **Autenticação (`login.html`):** Interface de login para controle de acesso ao sistema.
* **Página Inicial (`index.html`):** Hub central de navegação entre as funcionalidades do catálogo.
* **Cadastro de Artistas (`cadastro_artista.html`):** Formulário dedicado à inclusão de informações sobre artistas e intérpretes.
* **Cadastro de Músicas (`cadastro_musica.html`):** Registro de novas faixas, vinculando dados como título, gênero, duração e artista.
* **Listagem de Músicas (`listagem_musicas.html`):** Exibição organizada do acervo musical cadastrado.
* **Estilização Unificada (`styles.css`):** Identidade visual consistente aplicada em todas as páginas da interface.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas e formulários.
* **CSS3:** Estilização, layout responsivo e identidade visual.
* **Visual Studio Code:** Ambiente de desenvolvimento configurado via `.vscode/settings.json`.

---

## 💻 Como Executar o Projeto

Por se tratar de uma aplicação front-end estática (HTML/CSS), não é necessária a instalação de dependências complexas:

1. **Clone ou extraia** os arquivos do projeto para uma pasta local.
2. Navegue até o diretório `sistema-musical/`.
3. Abra o arquivo `index.html` (ou `login.html`) diretamente em qualquer navegador web moderno (Chrome, Firefox, Edge, Safari).
4. *(Opcional)* Caso utilize o **VS Code**, recomenda-se abrir a pasta do projeto e utilizar a extensão **Live Server** para visualização em tempo real.
